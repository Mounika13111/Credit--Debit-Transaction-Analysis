# Credit & Debit Transaction Analysis Dashboard | Power BI

## Project Overview
This project uses Microsoft Power BI to analyze credit and debit transactions, transaction methods, customer activity, bank transaction volumes, and high-risk transactions.

## Project Objectives
- Monitor total credit amount, total debit amount, and total transactions.
- Analyze the credit-to-debit ratio and net transaction amount.
- Measure account activity using the account activity ratio.
- Compare transactions by payment method and month.
- Identify high-risk transactions.
- Analyze the top five customers by transaction volume.
- Compare transaction volumes across banks and transaction amounts across branches.

## Dashboard Features
- **KPI Cards:** Total Credit Amount, Total Debit Amount, Credit-to-Debit Ratio, Total Transactions, Net Transaction Amount, and Account Activity Ratio.
- **Transaction Method Analysis:** Debit Card, Bank Transfer, and Credit Card.
- **Monthly Trend:** Transaction activity from January to December.
- **Risk Analysis:** Normal versus high-risk transactions.
- **Customer Analysis:** Top five customers by transaction count.
- **Bank Analysis:** Transaction volume by bank.
- **Branch Analysis:** Transaction amount by branch.
